# Локальное HTML-приложение для шифрования файлов в PNG

## Цель

Пользователь может зашифровать файл размером до 10 МБ паролем, получить PNG и позднее восстановить исходный файл через ту же HTML-страницу. Доступны два варианта PNG: новая картинка с зашифрованными данными и выбранная пользователем картинка, в пикселях которой скрыты данные. Все действия происходят локально в браузере без сервера и внешних библиотек.

## Пользовательские сценарии

1. **Скрыть в картинке.** Пользователь выбирает файл, картинку-носитель и пароль. Приложение показывает доступную вместимость картинки, проверяет, что зашифрованный пакет поместится, и выдаёт PNG для скачивания.
2. **Создать PNG с данными.** Пользователь выбирает файл и пароль. Приложение создаёт PNG подходящего размера и выдаёт его для скачивания.
3. **Извлечь файл.** Пользователь выбирает PNG, созданный одним из двух режимов, и вводит пароль. Приложение обнаруживает формат, расшифровывает пакет и предлагает скачать файл с исходным именем.

## Формат данных и шифрование

- Использовать встроенный Web Crypto API: PBKDF2 для получения ключа из пароля, случайные соль и IV, AES-GCM 256 для шифрования и проверки целостности.
- В зашифрованный пакет входят имя файла, MIME-тип и содержимое. Имя и тип не остаются открытыми в изображении.
- Внешний двоичный контейнер содержит сигнатуру, версию формата, длину, соль, IV и шифротекст. Версия позволяет отклонять неподдерживаемые изображения без попыток угадать формат.
- Режим новой картинки записывает байты контейнера в RGB-каналы пикселей непрозрачного PNG.
- Скрытый режим записывает биты контейнера в младшие биты RGB-каналов картинки-носителя и сохраняет результат как PNG без изменения размеров. Прозрачный носитель перед записью сводится на белый фон, чтобы цветовые байты стабильно читались после повторного открытия.
- Извлечение сначала проверяет сигнатуру режима новой картинки, затем сигнатуру скрытого режима. Другие изображения отклоняются.

## Интерфейс

Одна автономная HTML-страница с переключением между тремя режимами. В формах есть выбор файлов, поле пароля с возможностью показать его, сведения о выбранном файле и вместимости носителя, состояние обработки и ссылка скачивания. Ошибки объясняют, что нужно исправить: слишком большой файл, недостаточная вместимость, неподходящий PNG, неверный пароль или повреждённые данные. После операции чувствительные данные не записываются в постоянное хранилище браузера.

## Ограничения и поведение

- Размер исходного файла: не более 10 МБ. В скрытом режиме предел также зависит от размеров картинки-носителя. Вместимость вычисляется до шифрования с учётом служебных данных.
- Для восстановления нужен исходный PNG без пересохранения в JPEG, изменения размеров или обработки редактором.
- Приложение работает в современных браузерах с Web Crypto, Canvas и File API. При отсутствии нужного API показывает сообщение о несовместимости.
- Выходной PNG может быть значительно больше исходного файла. Пароль не восстанавливается приложением.

## Проверка

- Полный цикл шифрования и извлечения для обоих режимов, включая совпадение байтов и имени файла.
- Неверный пароль и повреждённый PNG не отдают содержимое файла.
- Отказ при превышении 10 МБ и при недостаточной вместимости носителя.
- Проверка скачанного PNG после повторной загрузки в браузер.
