# Imaginator — файл в картинке

Локальная HTML-страница для шифрования файла в PNG. Можно создать одну картинку, разбить большой файл на несколько PNG или скрыть небольшой файл в выбранном изображении. Для извлечения нужен пароль и оригинальные PNG. Файлы и пароль остаются на устройстве; приложение работает без сервера, внешних библиотек и постоянного хранилища браузера.

## Запуск

Скачайте `index.html` из репозитория или клонируйте проект:

```sh
git clone https://github.com/cpu-fan/imaginator.git
cd imaginator
```

Откройте один файл `index.html` напрямую в современном браузере. Стили и JavaScript встроены в него; интернет, локальный сервер и другие файлы проекта не требуются. Нужны Web Crypto, File API и Canvas. Если браузер отключает Web Crypto для локальных файлов, используйте браузер, поддерживающий `file:` как безопасный контекст.

Для разработки редактируйте `index.template.html`, `styles.css`, `file-parts.js`, `vault-core.js`, `image-codec.js`, `directory-zip.js` и `app.js`. Пересоберите переносимый файл: `node scripts/build-standalone.js`. Получателю нужен только итоговый `index.html`.

## Сведения о сборке

Под основной строкой футера готового HTML по центру отображаются дата сборки по Москве и короткий хэш коммита Git через точку. Ещё ниже находится ссылка на Telegram автора: [@azazaaat](https://t.me/azazaaat). Дата показывается без времени. Эти значения встраиваются при запуске `node scripts/build-standalone.js` и остаются доступными офлайн; открытие страницы не меняет дату сборки.

Хэш относится к `HEAD` на момент сборки. Если шаблон, стили, JavaScript или скрипт сборки отличаются от этого коммита, добавляется `-dev`. Изменения только в готовом `index.html`, тестах и документации не влияют на эту пометку. При сборке из исходников без Git вместо хэша отображается «недоступен».

Для воспроизводимой сборки можно задать `SOURCE_DATE_EPOCH` — Unix-время в секундах, например `SOURCE_DATE_EPOCH=1790807400 node scripts/build-standalone.js`. Без этой переменной используется текущее время. Готовый HTML хранится в Git, поэтому хэш в нём указывает на коммит, существовавший до сохранения этого HTML в следующем коммите.

## Выбор папки

В обоих режимах шифрования переключатель «Что зашифровать» предлагает «Файл» или «Папка → ZIP». После выбора папки страница показывает имя архива, количество файлов и полный размер ZIP. При запуске шифрования папка автоматически упаковывается в ZIP на устройстве, а затем обрабатывается как обычный файл. При восстановлении скачивается `имя-папки.zip`; распакуйте его обычным архиватором.

В ZIP сохраняются выбранная корневая папка, пути вложенных файлов, их содержимое и время изменения с точностью формата ZIP. Архив создаётся **без сжатия**: его размер немного больше суммы размеров файлов, зато расчёт частей точен до запуска. Архивация не требует интернета или внешних библиотек. Файлы читаются для контрольной суммы последовательно, блоками до 1 MB; готовый архив и результаты всё равно занимают память браузера.

Ограничения применяются к полному ZIP, включая служебные данные: до 512 MB в режиме создания PNG, до 64 MB в одной части, до 10 MB при скрытии в выбранной картинке. В папке допускается до 65535 файлов. Браузер передаёт файлы, поэтому пустые папки не сохраняются; полностью пустую папку выбрать для шифрования нельзя. Выбор папки зависит от поддержки `webkitdirectory`; в неподдерживаемом браузере доступен выбор обычного файла. Смена «Файл / Папка» очищает выбранный источник и прежние результаты.

## Создание PNG и разбивка

В режиме «Создать PNG с данными» выберите файл, карточку способа упаковки и пароль. Настройки количества или размера частей появляются под карточками после выбора соответствующего способа:

- **Один PNG** — до 64 MB исходных данных.
- **По количеству частей** — файл делится примерно поровну; разница размеров не больше одного байта.
- **По размеру части** — введите своё значение в kB или MB. Допустимы дробные значения с точкой или запятой, например `2,5` MB. Последняя часть содержит остаток.

Выбранный размер относится к исходным данным, а не к готовой картинке. PNG содержит шифрование и служебные данные и может быть больше. 1 kB = 1024 байта; 1 MB = 1048576 байт. Размер округляется вниз до целого байта.

Пределы: файл до 512 MB, данные части до 64 MB, максимум 1000 частей. Приложение заранее показывает расчёт и отказывается начинать при неверных параметрах. Например, 37 MB на 4 части — по 9,25 MB; при размере части 20 MB — две части 20 и 17 MB.

После создания скачайте **все PNG** по отдельным ссылкам. Части создаются последовательно, но готовые PNG остаются в памяти до смены настроек или закрытия страницы. Пределы не гарантируют достаточную память на любом устройстве. При нехватке ресурсов уменьшите размер части; для очень большого набора может потребоваться уменьшить и исходный файл.

## Восстановление

В режиме «Извлечь файл» выберите все PNG одного набора одновременно и введите общий пароль. Порядок и имена картинок не важны: номера частей и сведения об исходном файле зашифрованы внутри. Приложение проверяет комплектность, принадлежность одному набору и целостность, затем предлагает скачать исходный файл с его именем и MIME-типом. Если MIME-тип отсутствовал, для скачивания используется `application/octet-stream`.

Не хватает части — сообщение перечислит её номер. Повторную часть нужно убрать. Части разных наборов, повреждённые данные и неверный пароль не дают файл для скачивания. Частичное восстановление и дозагрузка между попытками не поддерживаются: каждый раз выбирайте полный набор. Во время сборки расшифрованные данные всего файла находятся в памяти.

**Совместимость:** эта версия открывает прежние одиночные PNG обоих режимов (FVLT v1) и новые наборы (FVLT v2). Все новые автоматически создаваемые PNG используют v2, даже если часть одна. Старые версии страницы не откроют их — передавайте обновлённый `index.html` вместе с PNG.

## Скрытие в выбранной картинке

В этом режиме разбивка не используется; исходный файл ограничен 10 MB и вместимостью носителя. Вместимость показывается после выбора файлов. Прозрачный носитель сводится на белый фон. Результат сохраняется как PNG в прежнем формате v1.

Пароль нигде не сохраняется и не восстанавливается. Не пересохраняйте PNG в JPEG, не меняйте размеры и не редактируйте: байты могут измениться и извлечение перестанет работать. Изменение файла, пароля, способа разбивки, параметров или вкладки удаляет прежние ссылки скачивания.

## Проверки

Для сборки и тестов нужен современный Node.js с Web Crypto и встроенным тестовым раннером. Установка npm-пакетов не требуется. Готовый `index.html` хранится в Git; после изменения исходников пересоберите его и включите результат в коммит.

Модульные и интеграционные проверки: `node --test tests/*.test.js`. Они проверяют расчёты, формат и криптографию, управление формами и автономную сборку. Тест формы использует тестовые Canvas/Image; настоящую PNG-кодировку браузера проверяйте отдельно.

Браузерный контрольный список:

- [ ] 37 MB / 4 части: скачать четыре PNG, выбрать их в другом порядке, восстановить файл и сравнить байты (`cmp` на macOS/Linux, `fc /b` на Windows).
- [ ] 37 MB / размер части 20 MB: скачать оба PNG, восстановить и сравнить байты. Проверить фактические размеры картинок.
- [ ] Дробный размер с точкой и запятой, смена единиц, один PNG, пустой файл и Unicode-имя.
- [ ] Пропуск части, копия части, смешение наборов, неверный пароль, повреждённый PNG и JPEG: понятная ошибка, без ссылки на файл.
- [ ] Изменение каждого параметра и переключение режима удаляет все прежние ссылки. После ошибки новая попытка работает.
- [ ] Старые PNG v1 обоих режимов открываются. Скрытие в прозрачном носителе сохраняет данные и сводит фон на белый; недостаточная вместимость и файл больше 10 MB отклоняются.
- [ ] Папка с вложенными файлами, Unicode-именами и пустым файлом: один PNG, несколько PNG и скрытие в носителе восстанавливают ZIP; архиватор открывает его, пути и содержимое совпадают. Пустые папки не включены.
- [ ] Смена «Файл / Папка» очищает источник и ссылки. Папка сверх лимита ZIP отклоняется до чтения содержимого; обычные файлы продолжают работать.
- [ ] Доступность клавиатурой, узкое окно и отсутствие нужных API: формы понятны, несовместимые среды не запускают обработку.
- [ ] Часть 64 MB и набор из файла 512 MB: измерить время и ресурсы на своём устройстве. Не переносить результаты одного браузера на все устройства.
