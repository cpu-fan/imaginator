# Файл в картинке

Локальная HTML-страница для шифрования файла в PNG. Можно создать новую картинку с данными или скрыть данные в выбранном изображении. Для извлечения нужен оригинальный PNG и пароль. Файл и пароль не отправляются на сервер; приложение не использует внешние библиотеки и постоянное хранилище браузера.

## Запуск

Откройте `index.html` напрямую в современном браузере. Интернет и локальный сервер не требуются. Нужны Web Crypto, File API и Canvas. Если браузер отключает Web Crypto для локальных файлов, откройте страницу в другом современном браузере, который поддерживает `file:` как безопасный контекст.

Исходный файл может быть размером от 0 до 10 МБ. При скрытии в картинке ограничение также зависит от числа её пикселей; вместимость и требуемый размер пакета показываются после выбора файлов. Прозрачный носитель перед записью сводится на белый фон. Результат всегда сохраняется как PNG.

Пароль нигде не сохраняется. Не пересохраняйте полученный PNG в JPEG, не меняйте его размеры и не редактируйте: после обработки байты могут измениться и извлечение перестанет работать. PNG с данными может занимать больше места, чем исходный файл.

## Проверка в браузере

Для сравнения байтов удобно подготовить небольшой файл с известным содержимым и сохранить его копию вне папки загрузок. После извлечения сравните файлы побайтно (`cmp` на macOS/Linux, `fc /b` на Windows) и проверьте имя скачанного файла.

- [ ] **Новая картинка:** выберите файл и пароль в режиме «Создать PNG с данными», скачайте PNG, затем выберите **скачанный** PNG в режиме «Извлечь файл». Проверьте исходное имя и побайтовое совпадение содержимого.
- [ ] **Скрытие в носителе:** выберите файл, достаточно большое изображение и пароль; убедитесь, что интерфейс показывает вместимость и что файл помещается. Скачайте PNG и повторно загрузите именно скачанный файл для извлечения. Проверьте исходное имя и побайтовое совпадение.
- [ ] **Неверный пароль:** для каждого режима извлечения введите другой пароль. Должна появиться понятная ошибка без ссылки на скачивание файла.
- [ ] **Недостаточная вместимость:** выберите маленькое изображение-носитель и файл, который в него не помещается. До шифрования должна показываться нехватка места; при отправке формы PNG не создаётся.
- [ ] **Прозрачный носитель:** выберите прозрачный PNG достаточного размера, затем скачайте результат и извлеките из него файл. Прозрачность результата заменяется белым фоном; содержимое и имя файла совпадают с исходными.
- [ ] **Пустой файл:** зашифруйте файл размером 0 байт, скачайте PNG и извлеките его. Результат имеет исходное имя и размер 0 байт.
- [ ] **Не PNG при извлечении:** загрузите JPEG или переименованный JPEG. Должна появиться подсказка выбрать PNG; ссылка на скачивание не появляется.
- [ ] **Отсутствующие API:** откройте страницу в среде без Web Crypto, File API или Canvas (либо временно отключите один из них в тестовом браузере). Формы должны быть отключены, а сообщение — объяснять несовместимость.
- [ ] **Размер более 10 МБ:** выберите файл больше предела. Интерфейс должен отказаться создавать PNG.
- [ ] **Смена результата:** создайте PNG, затем измените входной файл или пароль либо переключите режим. Старая ссылка скачивания должна исчезнуть.

Проверка модулей из терминала: `node --test tests/*.test.js`.
